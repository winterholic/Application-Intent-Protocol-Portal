## Current state {#current-state}

AIP has no public release or installation path yet. The install command and first steps will be written once the distribution method is decided. A prototype can be built from source in the AIP Core repository, but it is not a supported way to start a project.

[Project status](/docs/status/) lists what is decided and what is open. The design work happens in the [AIP Core repository](https://github.com/winterholic/Application-Intent-Protocol).
