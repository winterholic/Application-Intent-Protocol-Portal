AIP は設計と検証が進行中です。このページは上記の日付時点の AIP Core の文書を反映し、それが変われば一緒に変わります。

> [!IMPORTANT]
> `Open` は、AIP がまだ答えを決めていないという意味です。人も AI コーディングエージェントも、AIP を説明するときやコードを書くときに、これらの項目を推測で埋めないでください。

## Decided {#decided}

| テーマ | 決定 |
|---|---|
| 目的 | バックエンドをなくさずに、アプリケーション固有のバックエンド実装とフロントエンド・バックエンドの二重保守を最小化する |
| 呼び出しモデル | 呼び出し側が必要なデータと操作を表現し、サーバーが決定して実行する |
| 読み取り | 呼び出し側が組み合わせた読み取りを、サーバーのポリシーのもとで実行する |
| 単純な書き込み | 変更ごとにサーバーの command を作る代わりに、可能な限り標準の形でサポートする |
| 製品の形 | 自前のポートで動く AIP サーバーフレームワークと公式フロントエンドライブラリ |
| エンジンとエコシステム | Rust エンジン、JavaScript/TypeScript・Python のエコシステム。JS/TS を特に重視する |
| 拡張 | サーバーの契約と統制のもとでの JS/TS・Python の公式拡張 |
| 構文の方向 | 定義を表現する AIP 固有の構造化された方法。宣言的なスタイルを好む |
| 自然言語メタデータ | 任意で宣言に結び付き、実行やセキュリティの根拠にはならない |
| チェック | サーバーの必須の安全チェックと任意の開発チェックを区別する |
| オープンソース | オープンソースとして開発し、外部からの貢献を歓迎する |

## Direction {#direction}

| テーマ | 方向 |
|---|---|
| 本番環境での未登録の読み取りの形 | セキュリティ・性能・コストの検証を前提に、ポリシーの範囲で許可 |
| 一括処理の失敗 | アトミックな操作は全成功か全失敗。部分成功のモードは検討中 |
| デプロイ環境 | 通常のサーバーとコンテナを優先。サーバーレスは後で分析 |
| 画面の同期 | 既定は再取得ベース。リアルタイムは任意機能の候補 |
| フロントエンドライブラリの範囲 | データアクセス、リクエスト作成、契約の扱い、状態の同期を優先 |

## Open {#open}

| テーマ | 問い |
|---|---|
| 定義の形式 | 独立した `.aip` ファイルが必要か、具体的な構文は何か |
| 書き込みの組み合わせ | 呼び出し側にどこまで書き込みの組み合わせの自由を与えるか、トランザクション境界 |
| 言語の同等性 | 最初のリリースで TS と Python の機能が同じか |
| フロントエンド統合 | フレームワーク非依存のコアを先にするか、React のような最初の公式統合を先にするか |
| 拡張エコシステム | サードパーティの拡張パッケージの初期範囲 |
| 拡張の分離 | 本番環境で拡張を実行する分離レベル |
| データベース | 対応 DB と capability モデル。現在の検証は PostgreSQL |
| 互換性 | 名前が変わった古いフィールドをどれだけ長く受け付けるか |
| 最初のリリースの呼び出し側 | 最初のリリースで誰がリクエストを直接書けるか |
| ライセンス | 具体的なオープンソースライセンス |

## プロトタイプの検証 {#prototype}

AIP Core リポジトリには、検証済みの部品を一つのサーバーに組み立てたプロトタイプがあります。2026-10-06 時点です。

- 運用 JWT の検証とサーバー側での actor への対応付け
- 計画を立ててトランザクションで適用するデータベースマイグレーション
- ローカルにインストールする TypeScript SDK と、契約から生成した型
- サーバーの統制のもとでの Node.js・Python の拡張
- macOS 上の実際の PostgreSQL で実行

これはプロトタイプのテスト結果であり、リリースの保証ではありません。外部 ID プロバイダー、TLS プロキシでのデプロイ、他の OS は試しておらず、プロトタイプの定義構文は最終版ではありません。詳細: [product/VERIFICATION.md](https://github.com/winterholic/Application-Intent-Protocol/blob/main/product/VERIFICATION.md)。
