AIP 1.0.0 は `aip` CLI と TypeScript・Python SDK のリリース候補として準備中で、まだリリースされていません。タグ、GitHub Release、レジストリのパッケージはなく、安定版ではありません。製品の定義、認証、ポリシー、マイグレーションを PostgreSQL 17 で提供します。重複した actor 宣言は検査で拒否されるようになりました。先に作った行の参照、制限付き算術、Decimal sum、拡張からの create は英語版の[表現力の変更](/docs/release-notes/#expressiveness)にあります。
