## 現在の状態 {#current-state}

AIP にはまだ公開リリースもインストール手段もありません。インストールコマンドと最初の手順は、配布方法が決まってから書きます。AIP Core リポジトリからプロトタイプをソースでビルドすることはできますが、プロジェクトを始めるためのサポートされた方法ではありません。

決まったことと開いていることは[現状](/ja/docs/status/)にあります。設計作業は [AIP Core リポジトリ](https://github.com/winterholic/Application-Intent-Protocol)で進んでいます。
