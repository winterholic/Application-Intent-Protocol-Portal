AIP는 설계와 검증이 진행 중이다. 아래 목록은 AIP Core 문서를 확인한 날짜 기준이며, Core가 바뀌면 함께 갱신한다.

> [!IMPORTANT]
> "미정"인 항목은 AIP가 아직 답을 정하지 않았다는 뜻이다. 사람이든 AI Coding Agent든 이 항목을 추측으로 채워 AIP의 동작처럼 설명하거나 구현하지 않는다.

## 확정된 기준 {#decided}

| 항목 | 내용 |
|---|---|
| 호출 모델 | 호출자가 필요한 데이터와 동작을 표현하고 서버가 권한과 실행을 최종 결정한다 |
| 읽기·쓰기 | 호출자 읽기, 단순 쓰기, 풍부한 표준 동작을 지향한다 |
| 제품 구조 | Rust 자체 포트 AIP 서버와 공식 프론트 SDK를 함께 제공한다 |
| 확장 | 표준 밖 동작은 JS/TS·Python 공식 확장으로 처리한다 |
| 자연어 설명 | 선택 사항이며 실행·보안의 근거가 아니다 |
| 검사 | 선택적 개발 검사와 필수 실행 안전 검사를 분리한다 |
| 공개 | 오픈소스이며 외부 기여를 환영한다 |

## 아직 정해지지 않은 것 {#open}

| 항목 | 상태 |
|---|---|
| 정의 작성 형식 | 독립 `.aip` 파일 여부와 구체 문법이 미정이다 |
| 쓰기 조합 | 호출자에게 어느 정도의 쓰기 조합 자유를 줄지 미정이다 |
| 언어 지원 범위 | 첫 출시에서 TS와 Python을 같은 수준으로 지원할지 미정이다 |
| 프론트 통합 | 프레임워크 독립 코어와 React 등 첫 통합 순서가 미정이다 |
| 확장 생태계 | 서드파티 확장·UI 라이브러리의 초기 범위가 미정이다 |
| 확장 격리 | 운영 환경의 확장 실행 격리 수준이 미정이다 |
| 데이터베이스 | 지원 DB 범위가 미정이다. 현재 검증은 PostgreSQL에서 한다 |
| 호환 기간 | 구버전 필드를 얼마나 오래 받아 줄지 미정이다 |
| 라이선스 | 구체 라이선스 조건을 결정 중이다 |

## 이 목록을 갱신하는 방법 {#updating}

AIP Core의 결정 문서에서 상태가 바뀌면 이 페이지를 고치고 frontmatter의 `checked` 날짜를 바꾼다. Core에서 확인할 수 없는 내용은 넣지 않는다.
