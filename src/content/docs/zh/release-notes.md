AIP 1.0.0 是 `aip` CLI 与 TypeScript、Python SDK 的发布候选，正在准备中，尚未发布。没有标签、GitHub Release 和注册表软件包，也不是稳定版。它在 PostgreSQL 17 上提供产品定义、认证、策略和迁移。重复的 actor 声明现在会被检查拒绝。对先前创建行的引用、有限算术、Decimal sum 和扩展中的 create 见英文版的[表现力变更](/docs/release-notes/#expressiveness)。锁限制、SDK 重试、诊断 JSON 和扩展 allowlist 详见[已知限制](/docs/known-limitations/#expressiveness)和[英文版](/docs/release-notes/#expressiveness)。
