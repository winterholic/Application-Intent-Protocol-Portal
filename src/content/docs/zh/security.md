## 表达不等于权限 {#expression-not-authority}

AIP 让前端表达所需的数据和操作，但这种便利绝不会把安全边界移到前端。无论调用方发送什么，允许的范围和执行方式都由服务器决定。`Decided`

## 服务器始终执行的检查 {#required-checks}

以下检查是必需的，始终由服务器执行。`Decided`

- 认证与授权
- 类型与输入约束
- 数据完整性
- 权限范围
- 事务安全
- 执行成本与资源限制

[为 AI 设计](/zh/docs/concepts/ai-first/#verification)中介绍的可选开发检查与此无关。不使用它们，也绝不会跳过必需检查。

## 扩展遵守同样的规则 {#extensions}

JS/TS 或 Python 扩展同样必须遵守服务器的安全策略和契约，不能借此绕过权限、成本限制或事务。在生产环境运行扩展的隔离级别为 `Open`。参见[扩展](/zh/docs/concepts/extensions/)。

## 自然语言不是安全输入 {#natural-language}

以自然语言编写的说明，绝不用于决定执行权限或安全。AIP 不会为了决定执行什么而逐个请求地解释自然语言。`Decided`

## 正在验证的方向 {#direction}

| 主题 | 方向 |
|---|---|
| 新字段 | 作为安全默认值，在被明确开放前对调用方隐藏。`Direction` |
| 读取中的隐藏副作用 | 仅在明确声明时允许。`Direction` |
| 会丢失数据或扩大权限的部署 | 默认需要明确批准并确认影响。`Direction` |
| 权限错误的详细程度 | 在不暴露私有资源或权限结构的前提下，对开发者有用。`Direction` |
| 开源与服务器访问 | 框架源码公开，并不意味着运行中的服务器公开；真实服务器通过认证、权限和资源策略限制访问。`Direction` |
