## 铺好的路与官方的出口 {#paved-road}

AIP 力求用标准能力和一种明确的标准表达覆盖尽可能多的场景。但真实的应用里总有任何标准都无法预见的逻辑。为此，AIP 提供 JavaScript/TypeScript 和 Python 官方扩展。`Decided`

扩展不是临时的变通手段，也不是每次都要特别批准的例外，而是 AIP 的正式组成部分。它唯一得不到的，是绕过服务器规则的途径。

## 扩展保留的约束 {#controls}

扩展与其他一切一样，在相同的控制下运行：

- 类型与数据访问契约
- 权限
- 执行成本限制
- 事务边界

扩展不得绕过服务器的安全策略。`Decided`

## 谁来编写 {#authors}

应用开发者和 AI 智能体用 JS/TS 或 Python 编写扩展。`Decided` 第三方扩展包生态在初期支持到什么程度为 `Open`。

## 仍在验证的内容 {#open}

- 在生产环境运行扩展的隔离技术。实验表明，仅把扩展放在单独进程中运行，并不能阻止它直接连接数据库，因此隔离级别为 `Open`。
- 扩展接口（ABI）以及 Rust 引擎与 JS/TS、Python 之间的执行边界，依据实测的成本与可扩展性来设计，而不是凭假设。
