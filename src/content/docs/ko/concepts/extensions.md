## 포장된 길과 공식 출구 {#paved-road}

AIP는 표준 기능과 하나의 명확한 표준 표현으로 최대한 많은 것을 다루려 한다. 그래도 실제 애플리케이션에는 어떤 표준도 미리 알 수 없는 로직이 있다. 이를 위해 AIP는 JavaScript/TypeScript와 Python 공식 확장을 제공한다. `Decided`

확장은 임시 우회 수단도, 매번 특별 승인이 필요한 예외도 아니다. AIP의 정식 구성 요소다. 다만 서버 규칙을 피해 가는 길은 주지 않는다.

## 확장이 지키는 것 {#controls}

확장도 다른 모든 것과 같은 통제 아래에서 실행된다.

- 타입과 데이터 접근 계약
- 권한
- 실행 비용 제한
- 트랜잭션 경계

확장은 서버의 보안 정책을 우회해서는 안 된다. `Decided`

## 누가 쓰는가 {#authors}

애플리케이션 개발자와 AI 에이전트가 JS/TS나 Python으로 확장을 쓴다. `Decided` 서드파티 확장 패키지 생태계를 처음에 어디까지 지원할지는 `Open`이다.

## 아직 검증 중인 것 {#open}

- 운영 환경에서 확장을 실행하는 격리 기술. 실험 결과 확장을 별도 프로세스로 띄우는 것만으로는 데이터베이스에 직접 연결하는 것을 막지 못했다. 격리 수준은 `Open`이다.
- 확장 인터페이스(ABI)와 Rust 엔진·JS/TS·Python 사이의 실행 경계는 가정하지 않고 실제 비용과 확장성을 측정해 설계한다.
