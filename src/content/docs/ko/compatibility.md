CLI와 두 SDK는 1.0.0이고 HTTP 프로토콜은 `aip-protocol/1.0`이다. 정의를 바꿔 계약 지문이 바뀌면 SDK 바인딩을 다시 만든다. 롤백에는 데이터베이스 백업이 필요하다.
진단·묶음 잠금·SDK 재시도·확장의 추가 계약은 [영어 원문](/docs/compatibility/#expressiveness)을 확인한다.
