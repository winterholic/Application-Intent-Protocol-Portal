AIP는 설계와 검증이 진행 중이다. 이 페이지는 위 날짜 기준의 AIP Core 문서를 반영하며, 그 문서가 바뀌면 함께 바뀐다.

> [!IMPORTANT]
> `Open`은 AIP가 아직 답을 정하지 않았다는 뜻이다. 사람이든 AI 코딩 에이전트든 AIP를 설명하거나 코드를 쓸 때 이 항목을 추측으로 채우지 않는다.

## Decided {#decided}

| 주제 | 결정 |
|---|---|
| 목적 | 백엔드를 없애지 않고, 애플리케이션별 백엔드 구현과 프론트·백엔드 이중 유지보수를 최소화한다 |
| 호출 모델 | 호출자가 필요한 데이터와 동작을 표현하고, 서버가 결정하고 실행한다 |
| 읽기 | 호출자가 조합한 읽기를 서버 정책 아래에서 실행한다 |
| 단순 쓰기 | 변경마다 서버 command를 만드는 대신 가능한 한 표준 형태로 지원한다 |
| 제품 형태 | 자체 포트에서 동작하는 AIP 서버 프레임워크와 공식 프론트엔드 라이브러리 |
| 엔진과 생태계 | Rust 엔진, JavaScript/TypeScript·Python 생태계. JS/TS를 특히 중요하게 본다 |
| 확장 | 서버의 계약과 통제 아래의 JS/TS·Python 공식 확장 |
| 문법 방향 | 정의를 표현하는 AIP 고유의 정형화된 방식. 선언형을 선호한다 |
| 자연어 메타데이터 | 선택 사항이며 선언에 붙고, 실행이나 보안의 근거가 아니다 |
| 검사 | 서버의 필수 안전 검사와 선택적 개발 검사를 구분한다 |
| 오픈소스 | 오픈소스로 개발하며 외부 기여를 환영한다 |

## Direction {#direction}

| 주제 | 방향 |
|---|---|
| 운영 환경의 미등록 읽기 형태 | 보안·성능·비용 검증을 전제로 정책 안에서 허용 |
| 일괄 처리 실패 | 원자적 작업은 전체 성공 또는 전체 실패. 부분 성공 모드는 검토 중 |
| 배포 환경 | 일반 서버와 컨테이너 우선. 서버리스는 이후 분석 |
| 화면 동기화 | 기본은 재조회. 실시간은 선택 기능 후보 |
| 프론트엔드 라이브러리 범위 | 데이터 접근, 요청 작성, 계약 처리, 상태 동기화 우선 |

## Open {#open}

| 주제 | 질문 |
|---|---|
| 정의 형식 | 독립 `.aip` 파일이 필요한지, 구체 문법은 무엇인지 |
| 쓰기 조합 | 호출자에게 쓰기 조합 자유를 어디까지 줄지, 트랜잭션 경계 |
| 언어 동등성 | 첫 출시에서 TS와 Python의 기능이 같은지 |
| 프론트엔드 통합 | 프레임워크 독립 코어를 먼저 할지, React 같은 첫 공식 통합을 먼저 할지 |
| 확장 생태계 | 서드파티 확장 패키지의 초기 범위 |
| 확장 격리 | 운영 환경에서 확장을 실행하는 격리 수준 |
| 데이터베이스 | 지원 DB와 capability 모델. 현재 검증은 PostgreSQL |
| 호환성 | 이름이 바뀐 옛 필드를 얼마나 오래 받아 줄지 |
| 첫 출시 호출자 | 첫 출시에서 누가 요청을 직접 작성할 수 있는지 |
| 라이선스 | 구체적인 오픈소스 라이선스 |

## 프로토타입 검증 {#prototype}

AIP Core 저장소에는 검증한 조각을 하나의 서버로 조립한 프로토타입이 있다. 2026-10-06 기준이다.

- 운영 JWT 검증과 서버 측 actor 연결
- 계획을 세우고 트랜잭션으로 적용하는 데이터베이스 마이그레이션
- 로컬 설치 TypeScript SDK와 계약에서 생성한 타입
- 서버 통제 아래의 Node.js·Python 확장
- macOS의 실제 PostgreSQL에서 실행

프로토타입의 시험 결과이지 릴리스의 보증이 아니다. 외부 ID 제공자, TLS 프록시 배포, 다른 운영체제는 시험하지 않았고, 프로토타입의 정의 문법은 최종이 아니다. 자세한 내용: [product/VERIFICATION.md](https://github.com/winterholic/Application-Intent-Protocol/blob/main/product/VERIFICATION.md).

## 이 페이지를 갱신하는 방법 {#updating}

AIP Core에서 결정이 바뀌면 이 페이지를 고치고 `checked` 날짜를 옮긴다. AIP Core로 추적할 수 없는 내용은 넣지 않는다.
