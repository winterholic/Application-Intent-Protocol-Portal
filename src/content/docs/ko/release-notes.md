AIP 1.0.0은 `aip` CLI와 TypeScript·Python SDK의 출시 후보로 준비 중이며 아직 출시하지 않았다. 태그, GitHub Release, 레지스트리 패키지가 없고 안정 릴리스가 아니다. 제품 정의, 인증, 정책, 마이그레이션을 PostgreSQL 17에서 제공한다. 중복 actor 선언은 이제 검사에서 거부한다. 앞서 만든 행의 참조, 제한 산술, Decimal sum, 확장의 create는 영어 원문의 [표현력 변경](/docs/release-notes/#expressiveness)에 있다. 잠금 한계, SDK 재시도, 진단 JSON과 확장 allowlist의 자세한 내용은 [알려진 한계](/docs/known-limitations/#expressiveness)와 [영어 정본](/docs/release-notes/#expressiveness)을 본다.
